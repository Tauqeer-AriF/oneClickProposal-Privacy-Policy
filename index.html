Privacy Policy

Last Updated: March 15, 2026

1. Introduction

OneClickProposal ("we", "our", "the Extension") is a Chrome browser extension that helps freelancers generate AI-powered job proposals on platforms such as Upwork, Fiverr, LinkedIn, and PeoplePerHour. We are committed to protecting your privacy and being fully transparent about how your data is handled. This Privacy Policy explains what data we collect, how we use it, how we store it, and your rights regarding your information.

2. Data We Collect

We collect only the minimum data necessary for the extension to function:

Data Type What It Is Where It Is Stored
Groq API Key Your personal API key entered in the extension settings Locally on your device via Chrome Storage only
Daily Usage Count Number of proposals generated today (for free tier enforcement) Locally on your device via Chrome Storage only
Job Description Text Text extracted from the job posting page when you click Generate Sent directly to Groq API — never stored by us

3. Data We Do NOT Collect

  • Your name, email address, or any personal identity information
  • Your browsing history or activity outside job platforms
  • Payment or financial information
  • Device information or IP addresses
  • Any data in the background — all actions are user-initiated only

4. How We Use Your Data

  • Groq API Key: Stored locally and used solely to authenticate your requests to the Groq API when generating proposals. It is never sent to our servers.
  • Daily Usage Count: Stored locally to track how many proposals you have generated today, enforcing the free tier limit of 3 proposals per day.
  • Job Description Text: Sent directly from your browser to the Groq API (api.groq.com) to generate a proposal. We do not intercept, log, or store this content.

5. Data Storage

All data stored by this extension is saved locally on your own device using the Chrome Storage API. We do not operate any servers, databases, or cloud infrastructure that stores your data. Uninstalling the extension removes all locally stored data from your device.

6. Data Sharing & Third Parties

We do not sell, rent, trade, or share your data with any third parties, with one exception:

  • Groq API (api.groq.com): When you click "Generate Proposal", the job description text is transmitted directly to the Groq API using your own API key. This transmission is necessary to generate the proposal. Please review Groq's Privacy Policy to understand how they handle this data.

We have no affiliation with Groq, Upwork, Fiverr, LinkedIn, or PeoplePerHour.

7. Permissions Used & Why

Permission Why It Is Needed
storage To save your Groq API key and daily proposal count locally on your device
host_permissions (upwork.com, fiverr.com, linkedin.com, peopleperhour.com) To inject the Generate Proposal button and read job descriptions on these platforms only

8. Data Retention

Data stored locally (API key and usage count) remains on your device until you either clear it manually in the extension settings or uninstall the extension. We do not retain any data on external servers because we do not collect any.

9. User Rights

You have full control over your data at all times:

  • Access: You can view your stored API key in the extension settings at any time.
  • Delete: You can clear your API key and usage data from the extension settings, or simply uninstall the extension.
  • Correction: You can update your API key at any time in the extension settings.
  • Portability: Your data is stored locally — you always have direct access to it.

10. Children's Privacy

OneClickProposal is not intended for children under the age of 13. We do not knowingly collect any data from children. If you believe a child has used this extension, please contact us and we will take appropriate action.

11. Security

Your Groq API key is stored locally using Chrome's built-in secure storage API and is never transmitted to any server other than Groq's official API endpoint. We strongly recommend that you do not share your API key with anyone and that you revoke it at console.groq.com if you believe it has been compromised.

12. Changes to This Policy

We may update this Privacy Policy from time to time. When we do, we will update the "Last Updated" date at the top of this page. We encourage you to review this policy periodically. Continued use of the extension after any changes constitutes your acceptance of the updated policy.
